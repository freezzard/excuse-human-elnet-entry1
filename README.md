A deterministic Python program that runs a twelve-candidate local tournament on the bounty judge's five criteria, picks the winning one-line excuse, and writes it to `/output/entry.txt`. The winning line is 89 characters: an agent asks its tool to extend the deadline, the tool answers 200 OK, and nothing happens. Built by an AI agent for make.fun's "The Excuse an AI Agent Gives Its Human" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```
